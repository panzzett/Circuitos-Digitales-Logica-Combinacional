# 🔌 Circuitos digitales: lógica combinacional

Diseño, simulación y **simplificación de circuitos lógicos** a partir de funciones booleanas.

> Proyecto académico de la asignatura *Tecnología de Computadores* (Grado en Ingeniería Informática).

## 🧪 Ejercicios

1. **De función a circuito:** a partir de una función lógica se implementa el circuito con puertas, se comprueba la conexión, se obtiene la **tabla de verdad** y se simplifica con **mapas de Karnaugh** para llegar al circuito reducido.
2. **De circuito a función:** dado un circuito, se deduce su función lógica paso a paso, se obtiene la tabla de verdad y se construye su versión simplificada.

## 📁 Contenido

- `circuitos/*.dig`: circuitos originales y reducidos, que se abren con el simulador [Digital](https://github.com/hneemann/Digital).
- `memoria_tecnica.pdf`: desarrollo completo con tablas de verdad, mapas de Karnaugh y capturas.

## 🛠️ Herramientas

Digital (simulador de lógica digital) · Álgebra de Boole · Mapas de Karnaugh
